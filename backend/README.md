# happyHealth Backend

Java 21 · Spring Boot 3.3.4 · Maven · H2 · Actuator

## Prerequisites
| Tool | Version |
|---|---|
| Java JDK | 21 (Eclipse Temurin recommended) |
| Maven | Not needed — use the included `mvnw` wrapper |
| Docker | Only for Compose startup |

## Run locally
```bash
# from backend/
./mvnw.cmd spring-boot:run    # Windows
./mvnw spring-boot:run        # Linux / macOS
